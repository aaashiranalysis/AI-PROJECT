Hexa-Ludo 🎲🛡️
Hexa-Ludo is a creative variation of the classic Ludo game, played on a 24-tile hexagonal board. It features both Player vs Player (PvP) and Player vs AI (PvAI) modes, power-up tiles, and basic AI using a simplified Minimax algorithm. The game includes dice-rolling animations and win animations for an immersive experience.

Features
🔷 24-tile Hexagonal Board – A unique board layout with hexagonal tiles.

🧑‍🤝‍🧑 3 Players – Player 1, Player 2, and AI.

🎲 Dice Rolling Animation – Visual effect for dice rolls.

⚡ Power-Up Tiles – Special tiles with additional benefits.

🧠 Basic AI – AI player that uses a simple Minimax algorithm to make moves.

🎉 Win Animation – Fun animation when a player wins.

🏆 End Game Screen – Displays the winner and final score.

How to Play
Roll the Dice – Press the Spacebar on your turn to roll the dice and move your player.

Power-Up Tiles – Some tiles contain power-ups. Land on these to get special benefits (like an extra roll or extra move).

Win the Game – The first player to reach tile 24 wins the game.

Game Modes
PvAI: Default mode with two human players and one AI.

To switch to PvP (Player vs Player mode), modify the game_mode variable in the code.
